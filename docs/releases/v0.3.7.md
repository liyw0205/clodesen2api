# v0.3.7

- Include the configurable account credit cooldown threshold introduced in v0.3.6, with a default of 100 and live updates from Settings > General > Accounts and Checkin.
- Persist the threshold with validation, CLI and environment overrides, source metadata and conflict recovery; the next balance check applies the new threshold.
- Fix the administration integration test fixture to keep its transaction within the rolling seven-day credit history window instead of using an expiring calendar date.
- Validate threshold persistence, pool and single-account cooldown behavior, and mobile and desktop settings layouts.

This patch release follows v0.3.6, whose package publication was blocked by the expired test fixture. Existing release tags and assets remain immutable.
