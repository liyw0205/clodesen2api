# v0.3.8

- Show a copyable Base URL below the API Keys heading, with layouts for desktop and mobile.
- Fix key and connection-template copying when the Clipboard API is unavailable or denied, including copying from modal dialogs. Failed copying still offers manual selection.
- Generate curl, Python and client JSON configurations for Chat, Responses, text-to-image and image-to-image. Image editing uses multipart file upload.
- Display conversation, text-to-image and image-to-image types below model names. Prefer configured endpoint policies, then upstream metadata, then local model-name mappings; unknown types remain explicit.
- Reuse model types when choosing connection endpoints and opening the call playground, including public aliases and upstream model mappings.
- Fix empty account pools falling back to legacy configuration credentials, which could crash account refresh. Cover both empty startup and removing the last account.
- Validate real clipboard contents, endpoint templates, model type resolution and layouts from 320 to 1440 pixels. Local Go tests, vet and all 28 web tests pass.

This patch release follows v0.3.7. Existing release tags and assets remain immutable.
