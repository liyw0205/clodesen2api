# v0.3.5

- Use the authenticated management session for the model call playground, without requiring or creating a client API key.
- Default Chat playground requests to streaming, show the first response chunk immediately, and preserve partial output on cancellation or an incomplete stream.
- Add dedicated management playground routes while keeping public `/v1/*` API-key authentication unchanged.
- Show per-request model estimates beside the test action, calculated per available account from the effective upstream model price; token-priced models and unknown balances remain unestimated.
- Add regression coverage for session authentication, same-origin protection, model policies, admission, audit attribution, streaming and responsive estimate layout.

This patch release follows v0.3.4. Existing release tags and assets remain immutable.
