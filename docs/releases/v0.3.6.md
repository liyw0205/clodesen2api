# v0.3.6

- Add a configurable account credit cooldown threshold under Settings > General > Accounts and Checkin, with a default of 100.
- Apply threshold changes without restarting; the next balance check cools accounts at or below the threshold and restores them above it.
- Persist the threshold in management settings and TOML, with CLI and environment overrides, input validation, source metadata and conflict recovery.
- Add regression coverage for default values, persistence, locked settings, pool and single-account cooldown behavior, and mobile and desktop layouts.

This patch release follows v0.3.5. Existing release tags and assets remain immutable.
