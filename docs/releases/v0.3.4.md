# v0.3.4

- Replace bottom navigation with a persistent desktop sidebar and a mobile drawer, with keyboard navigation, focus handling and short-screen scrolling.
- Expand alerts to 13 independently configured channels: Webhook, Bark, ServerChan, PushPlus, Telegram, WeCom, DingTalk, Feishu, SMTP, ntfy, WxPusher, Gotify and PushDeer. Add draft test sending, credential redaction, explicit credential clearing, delivery retries and recovery notifications.
- Use a floating selector for account routing and keep both routing and update-source panels inside the screen. Preserve fixed, round-robin and random routing; remove account weights and the experimental routing modes, while mapping stored retired modes to fixed selection.
- Add account search, filters, sorting and batch actions, URL-restored navigation, a persistent task center, connection templates, request diagnostics and a client-key call playground.
- Add resilient statistics loading, indexed audit filtering and pagination, 31-day compact reports with CSV export, grouped settings, configurable resource cache TTLs and scheduled backups with retention.
- Add persistent login backoff, readiness and runtime health reporting, configuration conflict recovery and management API documentation. Split management and browser code into focused modules.

## Upgrade Notes

The control database upgrades to schema 3 with a pre-migration snapshot. Schema 2 backups remain supported. Report coverage begins when collection starts; older request details are not presented as complete 31-day history. Credit estimates retain their separate seven-day scope.

Alerts and scheduled backups are disabled by default. Existing notification credentials remain private in management responses. New account requests reject the removed weight field; stored legacy routing values remain readable.

## Validation

Local Go tests, vet and all 22 browser flows pass, including desktop, mobile and short landscape layouts. Release CI also checks Go 1.23 and stable, Linux race detection and five platform packages.

This release follows v0.3.3. Existing release tags and assets remain immutable.
